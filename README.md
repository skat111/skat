# Скат: свой голосовой ассистент на колонке «Маруся Мини»

Скат превращает колонку VK «Капсула Мини» («Маруся Мини», Amlogic A113X) в вашу собственную голосовую колонку: слово «Скат» ловится
**прямо на колонке** (без облака), а умная часть работает на вашем сервере и в API, которые вы выбираете сами.

> Это неофициальный любительский проект. Не связан с VK, Яндексом, DeepSeek и OpenAI. Прошивка колонки может лишить гарантии и, при ошибке,
> превратить её в кирпич: делайте резервную копию заводской прошивки и всё остальное на свой риск.
> Встроенный характер Ската грубоватый (с матом, чёрным юмором): его можно заменить одной переменной `SKAT_PERSONA`.

## Что умеет

- **Диалог голосом**: слово «Скат» → распознавание (Yandex SpeechKit) → мозг (DeepSeek или ChatGPT, переключается голосом) → голос (Yandex или OpenAI, с эмоциями).
- **Живой разговор** через OpenAI Realtime: ответ начинается через ~1 секунду, можно болтать без слова «Скат» перед каждой фразой.
- **Поиск в интернете** и свежие данные, продолжение диалога после вопроса.
- **Музыка Яндекса** (через Raspberry Pi): «Моя волна», жанры, треки, «дальше / назад / пауза» без слова «Скат» при музыке.
- **Звук компьютера на колонке** («Скат, звук с компьютера»).
- **Управление ПК**: открыть/закрыть программы и сайты, «посмотри на экран и подскажи», нарисовать картинку и показать её на мониторе.
- **Свет**: RGB-лента ZENGGE по Bluetooth и лента монитора Skydimo по USB: цвета эмоций, пульс голосом, бит музыки, голосовые команды.
- Эмоции: глаза на циферблате, цвета кольца, интонация голоса.
- Эхоподавление (SpeexDSP): колонка слышит «Скат» поверх громкой музыки.

Слово пробуждения: свой детектор «Скат» (обучается под ваш голос, `training/`) или заводская модель «Маруся» из прошивки колонки ([docs/MARUSIA_WAKE.md](docs/MARUSIA_WAKE.md)): она надёжнее и почти не откликается на шум.

## Как это устроено

```
 колонка (Alpine)           ваш сервер (Linux, публичный IP)            облака
 ┌───────────────┐  HTTPS   ┌──────────────────────────────┐   ┌─ Yandex SpeechKit (STT, TTS)
 │ слово «Скат»  │ ───────▶ │ server.py                    │ ──┼─ DeepSeek / OpenAI (мозг, голос, картинки)
 │ микрофон, VAD │ ◀─────── │ диалог, инструменты, эмоции  │   └─ OpenAI Realtime (живой разговор)
 │ кольцо, звук  │          └──────────────────────────────┘
 └──┬───┬───┬────┘
    │   │   └─ ПК (Windows): pc/pcagent.py — программы, экран, звук ПК, картинки
    │   └───── Raspberry Pi: pi/musicd.py (Яндекс Музыка), pi/ledd.py (ленты)
    └───────── локальная сеть
```
Подробно: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что нужно

| Что | Зачем | Обязательно |
|---|---|---|
| Колонка «Капсула Мини» с root по SSH и Alpine Linux | сам ассистент | да ([docs/FIRMWARE.md](docs/FIRMWARE.md)) |
| Linux-сервер с публичным IP (маленького VPS хватает), Python 3.11+ | мозг и связка с API | да |
| Ключ Yandex Cloud (SpeechKit) | распознавание речи и голос | да |
| Ключ DeepSeek | быстрый и дешёвый мозг | да (или только OpenAI, см. гайд) |
| Ключ OpenAI | ChatGPT, голос, рисование, живой разговор | нет |
| Raspberry Pi | музыка Яндекса, ленты по Bluetooth/USB | нет |
| Windows-ПК | управление программами, экраном, звук ПК | нет |

**Ключи вы заводите сами и храните только на своём сервере** (`/etc/skat.env`, права 600). В репозитории ключей нет и быть не должно.

## Быстрый старт

1. Подготовьте колонку: [docs/FIRMWARE.md](docs/FIRMWARE.md).
2. Сервер: `sudo server/install.sh` (скрипт спросит ключи и выпустит сертификат).
3. Колонка: заполните `speaker/skat.conf.example` (адрес сервера и токен) и выполните `speaker/deploy.sh root@IP_колонки cert.pem`.
4. По желанию Pi (`pi/install.sh`) и ПК (`pc/install_pc.py`).

Пошагово с проверками на каждом этапе: [docs/GUIDE.md](docs/GUIDE.md). Если что-то не работает: [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

## Состояние проекта

Всё проверено только на одной установке автора (колонка «Капсула Мини», сервер в Германии, Raspberry Pi 4). Установочные скрипты написаны
по этой установке и на чужих машинах могут потребовать правок: присылайте исправления. Заводских звуков и анимаций колонки в репозитории нет
(это собственность производителя): вместо них используются простые свои, фирменные можно подложить в `/opt/skat/led` и `/opt/skat/snd`.

## Безопасность

- Колонка и сервер общаются по HTTPS с закреплённым сертификатом и общим токеном.
- Агент ПК принимает запросы только из вашей подсети и только с токеном, действия из фиксированного списка.
- Не публикуйте `/etc/skat.env`, `/etc/skat.conf`, `config.json` агента и токены: если токен утёк, замените его на сервере и колонке.
