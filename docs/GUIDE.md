# Пошаговый гайд

Идите по порядку, после каждого шага есть проверка. Если проверка не прошла, дальше не идите: смотрите [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## 0. Что подготовить

1. Колонка «Капсула Мини» с Alpine Linux и root по SSH: [FIRMWARE.md](FIRMWARE.md). Проверка: `ssh root@IP_колонки` пускает.
2. Linux-сервер с публичным адресом (VPS), на нём `python3 --version` показывает 3.11 или новее. Порт 8765/tcp должен быть открыт.
   Сервер лучше держать в стране, откуда доступны Yandex Cloud и нужные вам нейросети.
3. Ключи (заводите сами):
   - **Yandex Cloud**: каталог, сервисный аккаунт с ролями `ai.speechkit-stt.user` и `ai.speechkit-tts.user`, для него API-ключ. Запишите ID каталога.
   - **DeepSeek**: API-ключ на platform.deepseek.com (пополните баланс).
   - **OpenAI** (необязательно): API-ключ на platform.openai.com.

## 1. Сервер

```
git clone <адрес этого репозитория> && cd <папка>
sudo server/install.sh ВНЕШНИЙ_IP_СЕРВЕРА
```
Скрипт копирует `server.py` в `/opt/skat`, выпускает самоподписанный сертификат на ваш IP, спрашивает ключи (ввод скрыт), записывает их в
`/etc/skat.env` (права 600), устанавливает службу `skat` и запускает её. В конце печатает **токен** (он же `SKAT_TOKEN`).

Проверка: `curl -k https://127.0.0.1:8765/health` отвечает `ok`; снаружи: `curl -k https://ВНЕШНИЙ_IP:8765/health`.
Тест без колонки (нужен токен из `/etc/skat.env`):
```
curl -k -X POST https://127.0.0.1:8765/ask -H "X-Token: ТОКЕН" -H "X-Force: 1" -H "Content-Type: text/plain; charset=utf-8" --data "привет, расскажи шутку" -o /tmp/otvet.raw
```
В `/tmp/otvet.raw` лежит звук ответа (PCM 24 кГц, 16 бит, моно); в `journalctl -u skat -n 20` видно, что услышал и сказал сервер.

## 2. Колонка

1. Скопируйте `/opt/skat/cert.pem` с сервера на свой компьютер.
2. Скопируйте `speaker/skat.conf.example` в `skat.conf`, впишите `URL=https://ВНЕШНИЙ_IP:8765` и `TOKEN=` (из шага 1).
3. Разложите файлы: `speaker/deploy.sh root@IP_КОЛОНКИ cert.pem` (ставит пакеты, копирует клиент, модель слова, скачивает признаки openWakeWord).
4. Положите настройки: `scp skat.conf root@IP_КОЛОНКИ:/etc/skat.conf`.
5. На колонке: `rc-update add skat default && rc-service skat start`.

Проверка: `tail -f /tmp/skat.log`; через ~15 секунд после старта колонка скажет «готов» (кольцо мигнёт), скажите «Скат, привет».
Если кольцо красное, колонка не достучалась до сервера: проверьте `URL`, `TOKEN`, сертификат и порт.

## 3. Настройка чувствительности

В `/etc/skat.conf`: `WAKE_THR` (0.93 по умолчанию) задаёт порог слова «Скат»: если откликается на лишние звуки, поднимите до 0.96–0.98; если не слышит вас,
опустите до 0.9. Слабые срабатывания дополнительно проверяет облако (в логе строки «проверка срабатывания»).
Модель обучена на голосе автора, для вашего голоса переобучите её: [training/README.md](../training/README.md).

## 4. Музыка и ленты (Raspberry Pi, необязательно)

```
sudo pi/install.sh
```
Скрипт ставит `ffmpeg`, Python-окружение с `yandex-music`, `bleak`, `pyserial`, службу `skat-music` и печатает `MUSIC_TOKEN`. Впишите в `/etc/skat.conf` на колонке:
```
MUSIC_URL=http://IP_PI:8780
MUSIC_TOKEN=...
```
и перезапустите клиент (`rc-service skat restart`). Токен Яндекс Музыки: проект `yandex-music-api` (без него играют только 30-секундные превью).

Лента IllumiHome DMRRBA-007 (Bluetooth): найдите её адрес (команда печатается в конце установки), впишите `LED_ADDR=` в `/etc/skat-music.env` и включите `systemctl enable --now skat-led`.
Лента монитора Skydimo (USB): воткните её в Pi, служба увидит `/dev/ttyUSB0` сама; число диодов: `SKY_LEDS=` (по умолчанию 65).

## 5. Агент на ПК (Windows, необязательно)

`python pc/install_pc.py IP_КОЛОНКИ` (ставит агент, автозапуск и печатает `PC_TOKEN`). В `/etc/skat.conf`: `PC_URL=http://IP_ПК:8790`, `PC_TOKEN=...`.
Для звука компьютера и ленты монитора: `pip install pyserial numpy PyAudioWPatch`.

## 6. Голосовые команды

| Скажите | Что будет |
|---|---|
| «Скат, ...» | обычный диалог |
| «Скат, живой разговор» | разговор без слова «Скат»; выход: любая кнопка колонки или «хватит» |
| «Скат, переключись на ChatGPT / на DeepSeek» | смена мозга (при сбое одной модели вторая подхватывает сама) |
| «Скат, говори голосом OpenAI / верни голос Яндекса» | смена голоса |
| «Скат, включи музыку / Мою волну / джаз» | музыка Яндекса |
| «дальше», «назад», «пауза» (при музыке) | управление без слова «Скат» |
| «Скат, звук с компьютера» / «выключи звук компьютера» | звук ПК на колонке |
| «Скат, сделай свет красным / выключи подсветку» | ленты |
| «Скат, нарисуй ...» | картинка на мониторе ПК |
| «Скат, открой хром / закрой телеграм» | программы ПК |

## 7. Обновление

Скопируйте новые файлы так же, как при установке (`server/install.sh` не затирает ключи; `speaker/deploy.sh` не затирает `/etc/skat.conf`), перезапустите: `systemctl restart skat` на сервере, `rc-service skat restart` на колонке.
