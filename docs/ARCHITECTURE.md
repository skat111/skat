# Архитектура

## Три слоя

**Колонка** (`speaker/`, Python на Alpine): единственный постоянный процесс `skat-client.py`.
- Один `arecord | sox` берёт все четыре PDM-микрофона, усредняет и приводит к 16 кГц.
- `wake.py`: слово «Скат» и команды «дальше/назад/пауза» ловит маленькая нейросеть (признаки openWakeWord + MLP) на самой колонке, каждые 80 мс.
  Слабые срабатывания (вероятность ниже 0,985) проверяет облако (`/verify`): слышит ли распознавание слово. Шорохи так отсекаются.
- После слова энергетический VAD режет фразу, она уходит на сервер (`/ask`), ответ приходит потоком PCM 24 кГц и сразу играет.
- `aec.py`: эхоподавление SpeexDSP: опорой служит играющая музыка, задержка между опорой и микрофоном оценивается сама (GCC-PHAT).
- `ring.py` / `clock.py`: кольцо из 12 диодов (SPI) и цифры циферблата (sysfs), эмоции, индикатор громкости голоса.
- `music.py`: поток музыки с Pi или звука ПК в `aplay` (с паузой на время ответа).

**Сервер** (`server/server.py`, только стандартная библиотека, TLS с закреплённым сертификатом):
- `/ask`: распознавание (Yandex STT) → правила быстрых команд (музыка, свет, ПК, переключение модели и голоса) → LLM со стримингом и инструментами
  (`web_search`, `play_music`, `music_control`, `pc_control`, `look_at_screen`, `light_control`, `draw_image`) → озвучка предложениями по мере поступления.
- Модель: DeepSeek или ChatGPT (формат OpenAI у обоих); выбранная недоступна — до первого слова тихо переходит на другую.
- Голос: Yandex SpeechKit v3 (роль и скорость по эмоции) или OpenAI `gpt-4o-mini-tts` (эмоция словами).
- `/live/*`: живой разговор. Колонка шлёт звук микрофона (24 кГц), сервер держит WebSocket к OpenAI Realtime (`wsclient.py`, свой минимальный клиент) и отдаёт голос обратно кадрами.
- `/followup`: после ответа колонка забирает отложенные действия: запустить музыку, цвет ленты, показать картинку.
- Остальное: `/verify`, `/say`, `/vision` (снимок экрана + вопрос), `/img/<id>`, `/health`.

**Дополнительные устройства**
- Pi: `musicd.py` (Яндекс Музыка: поиск, «Моя волна», PCM 48 кГц по HTTP), `ledd.py` (лента IllumiHome DMRRBA-007 по BLE и Skydimo по USB; цвета по HTTP).
- ПК: `pcagent.py` (Windows): `/do` (список действий), `/screenshot`, `/show` (картинка), `/audio` (звук компьютера потоком), `/sky/*`.

## Безопасность

Токен в заголовке `X-Token` у каждой службы. Сервер Ската: TLS с самоподписанным сертификатом, который колонка проверяет по файлу.
Службы в домашней сети (Pi, ПК) слушают HTTP по токену; агент ПК пускает только свою подсеть. Адреса Pi и ПК колонка находит сама
(перебор подсети с проверкой токена), если после перезагрузки роутера они поменялись.

## Конфигурация

Сервер: `/etc/skat.env`. Колонка: `/etc/skat.conf`. Pi: `/etc/skat-music.env`. ПК: `%LOCALAPPDATA%\SkatPC\config.json`. Примеры лежат рядом (`*.example`).
