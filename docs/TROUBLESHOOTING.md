# Если что-то не работает

Логи: колонка `/tmp/skat.log` (`tail -f`), сервер `journalctl -u skat -f`, Pi `journalctl -u skat-music -u skat-led -f`, ПК `%LOCALAPPDATA%\SkatPC\agent.log`.

| Симптом | Причина и что делать |
|---|---|
| Кольцо красное после слова «Скат» | колонка не достучалась до сервера: проверьте `URL`/`TOKEN`/`CERT` в `/etc/skat.conf`, `curl -k https://IP:8765/health` с колонки, порт 8765 на сервере |
| Колонка вообще не откликается на «Скат» | `WAKE_THR` слишком высокий (опустите до 0.9); микрофон выключен кнопкой (красный индикатор); в логе ищите `wake p=`. Модель обучена на чужом голосе: переобучите (`training/`) |
| Откликается на шорохи, клавиши | поднимите `WAKE_THR` до 0.96–0.98; слабые срабатывания и так проверяет облако (строки «проверка срабатывания» в логе); для надёжности соберите записи ложных срабатываний и дообучите модель (`/tmp/wakes/*.raw` при `DEBUG=1`) |
| «Не нашёл такую музыку» / музыка не играет | `MUSIC_URL` и `MUSIC_TOKEN` в `/etc/skat.conf`; `curl -H "X-Token: ..." http://IP_PI:8780/now` на Pi; токен Яндекс Музыки; после перезагрузки роутера у Pi мог смениться адрес (клиент ищет сам, это занимает до минуты) |
| Музыка или звук ПК играют слишком медленно | у `aplay` для музыки должна быть частота 48000 (`PLAY_MUSIC` в клиенте), голос ассистента играет в 24000 |
| Речь Ската рвётся | Wi-Fi колонки или интернет-канал не тянут поток; голос идёт по 48 КБ/с (24 кГц): проверьте скорость канала до сервера |
| Звук ПК запаздывает | буфер `PCAUDIO_BUF` (мс) в `/etc/skat.conf`; меньше буфер — меньше задержка, но чувствительнее к рывкам сети. Замерить: `pc/av_sync_test.html` |
| Лента IllumiHome не меняет цвет, в логе «лента не найдена» | контроллер держит одно соединение: закройте приложение IllumiHome на телефоне; зависшее соединение сбрасывается `btmgmt --index N power off && power on` (раскомментируйте `ExecStopPost` в `skat-led.service`) |
| Лента Skydimo светит только по краям | перед кадрами нужно приветствие `Moni-A` (ledd.py и агент ПК делают его сами); не запускайте одновременно приложение Skydimo, порт один |
| ChatGPT не отвечает | `OPENAI_API_KEY` в `/etc/skat.env`; в `journalctl -u skat` строки `llm openai error`; пока он недоступен, отвечает DeepSeek |
| «Скат, живой разговор» не включается | нужен `OPENAI_API_KEY`; в журнале сервера ищите `[live] start error` |
| Картинка не появляется на мониторе | агент ПК запущен? (`PC_URL`, `PC_TOKEN`), порт 8790, логи агента |

## Сбросить всё и начать заново

Сервер: `systemctl stop skat; rm /etc/skat.env` и снова `server/install.sh`. Колонка: `rc-service skat stop; rm /etc/skat.conf`.
