# Агент на ПК (Windows, необязательно)

Позволяет Скату открывать и закрывать программы и сайты, показывать картинки, делать снимок экрана («посмотри и подскажи»)
и передавать звук компьютера на колонку. Работает только с токеном и только из вашей домашней подсети, список разрешённых действий
фиксирован: удаление файлов, выключение и произвольные команды не поддерживаются.

```
python install_pc.py IP_КОЛОНКИ      # ставит в %LOCALAPPDATA%\SkatPC, делает автозапуск, печатает PC_TOKEN
pip install pyserial numpy PyAudioWPatch   # только для ленты Skydimo и звука компьютера
```
PC_URL (`http://IP_ПК:8790`) и PC_TOKEN впишите в `/etc/skat.conf` на колонке.
`av_sync_test.html` — страница для замера задержки звука между ПК и колонкой (вспышка + щелчок, ползунок).
