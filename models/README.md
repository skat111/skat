# Модель слова «Скат»

`skat_model.npz` — маленькая нейросеть (MLP) поверх признаков openWakeWord; на колонке она распознаёт «Скат» и три команды при музыке
(«дальше», «назад», «пауза»). Обучена на синтетических голосах (Yandex TTS), открытой русской речи (Golos, SOVA) и записях автора, поэтому
**лучше всего слышит голос автора**. Для вашего голоса и комнаты переобучите: `training/README.md`.
Признаки `melspectrogram.onnx` и `embedding_model.onnx` (openWakeWord, Apache-2.0) скрипт `speaker/deploy.sh` скачивает на колонку сам.
